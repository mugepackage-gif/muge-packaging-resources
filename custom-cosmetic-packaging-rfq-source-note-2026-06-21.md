- product type, size and weight: jar, bottle, tube, palette, set or fragrance item
- retail channel: ecommerce, shelf display, gift set or subscription kit
- inner support need: insert, tray, divider or foam alternative direction

- artwork status, color direction and reference packaging photos
- destination-market document review request if applicable
