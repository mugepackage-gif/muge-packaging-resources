## Buyer inputs before requesting a quote

- Product dimensions for jars, bottles, tubes, sachets or sample units.
- Number of products per set and whether the set is for retail shelf, gift, ecommerce, discovery kit or PR package.
- Box structure direction such as rigid box, folding carton, sleeve, drawer box or paperboard set box.
- Inner tray, divider, insert, label, sleeve or protective structure requirement.
- Surface finish references such as matte, soft-touch, foil, embossing, spot UV or specialty paper direction.
- Artwork readiness, dieline need, color reference and target market.
- Quantity direction for review, without using fixed public MOQ claims before project confirmation.
- Any cosmetic regulatory, product-contact, sustainability, destination-market or certification document request that must be reviewed before external claims.

## Decision matrix

| Dimension | Weak brief | Stronger brief |
|---|---|---|
| Product set layout | Ask for skincare set packaging without product count, dimensions or set layout. | Send each item dimension, product count, bottle or jar layout, sample size and insert/divider needs before sampling. |
| Retail vs ecommerce use | Use one brief for retail shelf, ecommerce shipping, discovery kits and PR sets. | Separate retail display, gift-ready presentation, ecommerce packing and sample discovery goals before quote review. |
| Structure and material | Request premium cosmetic packaging without box structure or material direction. | Define rigid box, folding carton, sleeve, drawer, paperboard or tray direction with material and finish preferences. |
| Artwork and finish | Request foil, embossing or soft-touch finish without artwork status. | Prepare logo files, dieline status, color reference, print area and finish priority before production review. |
| Claim boundary | Ask for cosmetic-safe, eco-certified or market-compliant packaging as a public claim. | Keep RFQ structure review separate from document-based cosmetic regulatory, product-contact, sustainability and destination-market claim review. |
