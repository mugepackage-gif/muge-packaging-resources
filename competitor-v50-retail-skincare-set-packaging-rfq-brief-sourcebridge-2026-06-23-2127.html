Buyer inputs before requesting a quote

  • Product dimensions for jars, bottles, tubes, sachets or sample units.
  • Number of products per set and whether the set is for retail shelf, gift, ecommerce, discovery kit or PR package.
  • Box structure direction such as rigid box, folding carton, sleeve, drawer box or paperboard set box.
  • Inner tray, divider, insert, label, sleeve or protective structure requirement.
  • Surface finish references such as matte, soft-touch, foil, embossing, spot UV or specialty paper direction.
  • Artwork readiness, dieline need, color reference and target market.
  • Quantity direction for review, without using fixed public MOQ claims before project confirmation.
  • Any cosmetic regulatory, product-contact, sustainability, destination-market or certification document request that must be reviewed before external claims.
