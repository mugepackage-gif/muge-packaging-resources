## Buyer inputs before requesting a quote

- Product dimensions, packed weight and number of items per gift box.
- Box structure direction such as lift-off lid, magnetic closure, drawer box, book-style box or sleeve box.
- Rigid board thickness direction, paper wrapping direction and whether the box needs an inner tray or divider.
- Use case: retail shelf, gift set, cosmetic set, electronics accessory, PR kit or premium unboxing.
- Surface finish references such as matte, soft-touch, foil, embossing, spot UV or specialty paper direction.
- Artwork readiness, dieline need, color reference and target market.
- Quantity direction for review, without using fixed public MOQ claims before project confirmation.
- Any sustainability, food-contact, product-contact, destination-market or certification document request that must be reviewed before external claims.

## Decision matrix

| Dimension | Weak brief | Stronger brief |
|---|---|---|
| Structure selection | Ask for a rigid gift box without opening style, item layout or insert requirements. | Define lift-off lid, magnetic closure, drawer, book-style or sleeve structure with product layout and insert needs. |
| Material direction | Request a premium rigid box without board or wrapping paper direction. | Send rigid board thickness direction, wrapping paper preference, finish reference and sample expectations before quote review. |
| Unboxing and retail channel | Use the same brief for retail shelf, gift set and PR package. | Separate retail display, gift-ready presentation, ecommerce delivery and PR unboxing goals before sampling. |
| Artwork and finishing | Request foil or special finish without artwork status or color reference. | Prepare logo files, print area, dieline status, color reference and finish priority before production review. |
| Claim boundary | Ask for certified, food-safe, eco-compliant or market-compliant rigid boxes as a public claim. | Keep structure and RFQ review separate from document-based sustainability, food-contact and destination-market claim review. |
